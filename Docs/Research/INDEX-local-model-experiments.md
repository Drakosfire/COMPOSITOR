# Local ingestion experiment index

This index follows the [ecosystem hardware research guide](https://github.com/Drakosfire/DungeonOverMind/blob/308700f19be93963b2d4d7598137ce9154e2ecf7/Docs/Guides/GUIDE-hardware-research-records.md). Local-model ingestion and retrieval experiments use one immutable identifier per bounded comparison. A record begins as a pre-registered plan, then appends exact activation, first-result, review, and scoring receipts. Preserve failed and interrupted runs. Private inputs and outputs remain outside Git; public records contain source-safe identities and limitations.

- [LOCAL-INGEST-001](LOCAL-INGEST-001.md) — **PROPOSED / NOT ACTIVE**. One 2024 PHB occupancy rule slice and one Conks opening adventure slice; deterministic read floor, local generator, and a separately gated local-generator-plus-Jev typed-decision arm. No model, provider, or GPU run has occurred.

Each record must pin the question and hypotheses before a run; source and dataset hashes; document-held-out policy; gold author, independent source critique, human seed review, and freeze status; backend, model bytes, quantization, prompt/settings; metric denominators; elapsed, queue, GPU memory/usage, reviewer time and monetary cost; failures; reproducible commands and durable artifact locations; independent review; and limitations. A blank field means **unmeasured**, not zero.
