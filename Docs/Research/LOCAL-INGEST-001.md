## Pre-registered questions and hypotheses

**H1:** A bounded local generator improves source-supported node, relation, and rule candidate coverage over existing deterministic reads without adding material or critical errors. **H2:** Given **the same frozen local candidates and evidence**, a Jev typed choice with an explicit `unresolved` option improves endpoint, condition, and uncertainty decisions over a local typed choice enough to justify its remote dependency. Citation containment is only a gate; semantic correctness requires source review. A rule candidate is compiler-ready only when all facts, qualifiers, exceptions, precedence, and source dependencies needed for the declared behavior are closed. Execution truth is measured separately at the RulesEngine boundary.

The comparison has three labels: **D** is exact deterministic evidence readback (RulesIngestion page-unit reads for PHB and COMPOSITOR package-local reads for Conks), with existing owner retrieval only if a query needs it; **L** is local generation plus a local typed decision over its own frozen alternatives; **L+J** reuses the same L candidates and asks Jev only for bounded typed choices. D and L can proceed when their exact source, runtime, and bounded execution scope are pinned. L+J awaits a working Jev credential and a recorded destination, applicable source-handling basis, model, and call/spend cap; the operator's research authorization is not a blanket prohibition on private inputs. A deterministic/oracle typed-choice replay may test the interface while Jev is unavailable, but it is not a Jev quality result. Keep prompts, candidate sets, retrieval scope, source exposure, and scoring cases identical across L and L+J; record any asymmetry.
