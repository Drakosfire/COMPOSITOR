# Package-based PDF review packet

Status: **unjudged private review context**, not a benchmark score or consumer witness.

The original owner A/B review packet assumes the first-result file contains its source package. The Sheep OCR2 run instead froze owner calls first, then assembled a separately pinned source package and a later JPEG reference package. `build_package_review_packet` checks those exact files and revisions without rewriting either first result. It verifies the source PDF and physical page count; source, owner evidence, assembly, gold, and freeze-record digests and their cross-links; every file named by the gold freeze record; base package identity and count; and optional derived asset lineage. With assets present, it reruns the byte-verifying asset projector and requires an identical derived package.

The builder uses physical PDF page anchors to suggest text and asset resources for each source-fidelity case. These are **page-local candidates**, not semantic matches or passes. It keeps the integration-contract denominator in a separate `unexecuted` list. Every source-fidelity review starts `null`; the existing explicit review validator can later check reviewer, rationale, verdict, and cited resource IDs against the immutable context. It does not infer Worldbuilding, Planning, Playing, rule, or asset interpretation success.
