`WorkspaceSelection` holds exact package revisions only in session memory. Selection reloads an immutable revision and returns its per-use readiness and issues; querying reloads the selected revisions and preserves package attribution and GM/PLAYER audience filtering. One package ID cannot silently switch revisions. Unload removes the exact active revision, so subsequent scoped and active-set queries cannot return it. There is no World, database, provider, publication, or product client handle in this API. The public North Mill fixture and a second authored fixture exercise same-name resources in distinct packages, scope, audience, unload/reselect, and an unchanged World-state sentinel. This proves only the local selection contract, not a product cache or model-context invalidation.

`propose_owner_inputs` makes one read-only handoff candidate from a selected source resource and a caller-supplied UTF-8 source body. It verifies the body SHA-256 against the package's exact source ID, requires a unique excerpt present in both the source body and resource text, and computes a half-open byte span and slice SHA-256. It retains the exact package revision, COMPOSITOR evidence locator, and any package issues; an incomplete draft can still be inspected without being presented as ready. It carries no source body bytes in its returned proposal. A missing or ambiguous span fails closed. The proposal leaves source classification, authority, visibility, admission ID, `space_id`, parent revision, and owner-generated source/evidence IDs unresolved.
