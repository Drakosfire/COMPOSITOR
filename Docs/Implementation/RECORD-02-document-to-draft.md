## Witness and boundary

`load_evidence_draft` requires the expected RulesIngestion ref and manifest digest, verifies source and artifact SHA-256 values, reads Stage A surface/AST/gates and Stage B EvidenceUnits/gates, and saves an immutable source package. Each evidence resource retains the exact Stage B unit text, page fingerprint, source-line span, recovery content version, and a reversible locator into the artifact JSON. Audience defaults to GM pending interpretation. The adapter does not infer narrative entities, rules, or relationships from prose.

The PDF route yields six units and the supplied-Markdown route four units; both preserve the same four declared content sentences. All fixture Stage A and B gates pass. The different unit topology is reported rather than normalized away. Missing pages, assets, artifacts, failed gates, and unit fingerprint/line-span mismatches become typed package diagnostics and limit readiness while available resources remain readable. A changed source digest or owner ref fails before assembly.

Run `PYTHONPATH=src python3 -m unittest discover -s tests -v` for the package and adapter witnesses. ## Limits and next dependency

This is an artifact-to-draft boundary, not a benchmark result or a demonstrated adventure first ingestion. Poppler text extraction is a narrow local route for a simple PDF and does not establish fidelity on illustrated adventures or complex tables. The supplied Markdown has separate provenance; its success is not credited to automatic PDF recovery. Arbitrary external page anchors and asset bytes need an owning data-handling run before they can be claimed. The next bite must pin both private one-shot sources, frozen gold versions, recipe, private run store/database, and finite provider/cost scope before scoring or interpretation. *Of Conks & Cons* gold is frozen privately after author/challenger/parent source review; *A Wild Sheep Chase* source paths are still requested from the operator and its gold is not frozen.
